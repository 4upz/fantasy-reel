# BrandLogo

The approved outlined Fantasy Reel logo without a navigation link. Use the
default horizontal lockup, `compact` for narrower placements, or `markOnly`
for the symbol alone. Preserve the asset's aspect ratio; pass `className` only
to control its size and layout. Use NavLogo when the logo should be a link.

The design-sync build embeds the same SVG files the app serves under
`/brand/v1/`, so the standalone renderer does not require that route.
