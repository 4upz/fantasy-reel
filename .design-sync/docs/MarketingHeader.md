# MarketingHeader

Public navigation with the approved full wordmark, How to play, Sign in and
Sign up. Below 640px, the header keeps Sign up visible and places the other
links in a right-aligned native popover. Set `currentPage="how-to-play"` for
the guide's current-page marker. Mount once at the top of a page; the popover
has a single document id and positions below that header. Bundle its imported
CSS module alongside the shared styles. Test mobile with a small viewport,
not just a narrow wrapper in a desktop canvas.
