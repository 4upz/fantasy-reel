# BidPriorityList

Ranks a team's pending pickup bids. Priority never decides who *wins* a
contest — the highest bid does that. It decides which of a team's own winning
bids it can keep when it wins more than it has roster room for.

Its capacity rule differs from the counterpick list in one way that matters
visually: a bid carrying a **conditional drop** brings its own slot, so it
fits even when ranked below the cut line. Those rows are marked "Brings its own
slot" and the line is drawn at the first bid that genuinely has nowhere to go.
