# SeriesListItem

One dashboard card per league, showing the season you would actually open. A
league with four years of history is still one entry: past seasons collapse
into a row underneath, each linking to its own final standings with the
champion in a gold chip.

The card *is* the current season — identical anatomy to the single-season row
it replaced — so a one-season league looks exactly as it always did.
