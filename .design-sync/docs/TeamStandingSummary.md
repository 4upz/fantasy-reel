# TeamStandingSummary

Display-only standings row: rank, team identity, movie counts, budget and
points. Renders a fragment; place it in a column with a gap inside the row's
card or activation button. Null budget hides that field. The default layout
moves details into a compact secondary row below the desktop breakpoint;
`inline` is for fixed-canvas examples. Selection, expansion and movie-detail
dialogs stay with the app container.
