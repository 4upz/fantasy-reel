# CounterpickMark

Small crimson target badge that distinguishes a counterpick from the movie
it targets. Position it inside a relatively positioned poster wrapper with
room for the badge to extend 7px above and left; do not clip that wrapper.
`label` defaults to “Counterpick” and supplies the screen-reader text and
hover title. Include visible counterpick context beside the poster where
the distinction matters; this mark is not a control.
