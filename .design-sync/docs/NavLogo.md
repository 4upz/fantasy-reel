# NavLogo

The approved gold film-strip speech-bubble symbol and outlined soft-white
Bricolage wordmark used in navigation. Preserve its accessible link name and
aspect ratio; do not retype the wordmark or recreate the symbol with CSS.

The build embeds its `/brand/v1/` SVG assets through the image host shim so the
same component renders without a Next.js public directory. See the canonical
brand package at `docs/brand/README.md` in the source repository.
