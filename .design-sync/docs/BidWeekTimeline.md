# BidWeekTimeline

The bidding week as a single bar, notched where new bids stop.

A filled track shows time elapsed, a notch marks the cutoff, and a label sits
under each half — so which half of the week you are standing in reads at a
glance, before opening the bid modal. Renders nothing when the league has the
cutoff disabled: there is no split to draw, and an always-full bar would be
furniture.
